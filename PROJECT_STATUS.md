# Project Status

This is an archived university group project developed for the TU Delft EE1L2 IP-2 “Building a Smart Robot” course.

- The repository focuses on FPGA/embedded control logic for the robot.
- It includes SystemVerilog source files, simulation testbenches, and FPGA constraint files.
- The code was created for an academic project and may depend on the original lab toolchain and hardware setup.
- This is not a maintained commercial robotics framework.
- The repository is preserved for portfolio and review purposes.
